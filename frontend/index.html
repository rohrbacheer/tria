O que é

A Tria é uma plataforma de atendimento de TI com IA. Você tira dúvidas com o Google Gemini e, se a orientação não resolve, a Tria abre o chamado já classificado e encaminhado para a equipe certa. Projeto individual do Desafio da Trilha de DevOps e IA Generativa (PUCPR).

Stack

Backend em FastAPI (Python 3.12) com saída estruturada do Gemini e dados em SQLite. Frontend em HTML, CSS e JavaScript puros. Testes com pytest (IA mockada, cobertura mínima de 70%), CI no GitHub Actions e deploy contínuo no Render.

Endpoints da API

  • GET /saude health check
  • POST /login abre a sessão
  • POST /perguntar envia a pergunta à IA
  • GET /historico perguntas já respondidas
  • GET /opcoes categorias e prioridades
  • POST /solicitacoes você classifica, a IA orienta
  • POST /solicitacoes/auto a Tria classifica e roteia para a equipe
  • GET /solicitacoes suas solicitações (técnico e admin veem a fila)
  • GET/POST /integracoes configuração da IA (só administrador)
